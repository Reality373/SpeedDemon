# Benchmark ledger

`experiments.csv` is a compact index of completed optimization experiments. It starts with a header only because no candidate solution has been benchmarked. Use [the experiment template](../docs/experiment-template.md) for reasoning and link raw evidence under `results/runs/`.

Keep local and official board IDs distinct. Source/data/harness identity belongs in each raw report. Do not log source-fetch duration, generator duration or host oracle execution as a candidate performance result.
