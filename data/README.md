# Local datasets

`generated/track-x/{scale}-seed{n}/` holds official-generator outputs. Seed 1 at tiny, sample and full scales has been prepared for A–D. Full inputs total 790,519,861 bytes and match the official calibration hashes. These files are ignored by Git.

See [resource provenance](../docs/resources.md) and [dataset identities](../resources/datasets.json). Oracle outputs belong in `results/reference-outputs/`, never beside submission code. Keep any future directly downloaded inputs under ignored `downloads/` and verify their hashes before use.
