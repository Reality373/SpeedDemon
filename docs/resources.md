## Reproduction commands

From the workspace root, generate one dataset (substitute track module, scale and seed as needed):

```bash
python3 -B resources/upstream/speed-demon-2026/generators/a_ingest.py \
  --seed 1 --scale full --out data/generated/track-a/full-seed1
sha256sum data/generated/track-a/full-seed1/requests.log
```

Module names are `a_ingest.py`, `b_index.py`, `c_join.py`, and `d_traverse.py`. Existing paths should be regenerated only deliberately. Compare hashes with `resources/datasets.json` for full seed 1; use an unchanged reference for other seeds.

Host-only oracle check:

```bash
python3 -B resources/upstream/speed-demon-2026/reference/a_ingest.py \
  --data data/generated/track-a/full-seed1 \
  --out results/reference-outputs/track-a/full-seed1
sha256sum results/reference-outputs/track-a/full-seed1/summary.txt
```

From `resources/upstream/speed-demon-2026/`, run the upstream tests:

```bash
python3 -B -m unittest discover -s tests -v
```

For actual sandbox execution use the [harness plan](harness.md); these commands do not substitute for it.
